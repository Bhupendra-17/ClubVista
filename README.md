# ClubVista

Website that helps any club or cell of a university create a year calendar of events and view reports/insights for better planning and engagement.  

> Built to simplify event visibility across the academic year and make coordination effortless.

## [🔗 Live Demo](https://schedule-3fe75.web.app/)
---

## ✨ Features

- **Event Calendar** – Add, edit, and browse events across months at a glance.  
- **Club/Cell Overview** – Organize events by club/cell; avoid schedule clashes. 
- **Reports & Insights** – Basic participation/summary views to review activity.  
- **Clean, Lightweight UI** – Fast to load; easy to navigate.

---

## 🧱 Tech Stack

- **Frontend:** React.js, Tailwind CSS, 
- **Build/Structure:** Severless backend with Firebase 
- **Firebase:** Firestore, Firebase Hosting
